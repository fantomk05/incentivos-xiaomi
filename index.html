¡Instalación nativa disponible! Tu navegador permite instalar esta herramienta como app directa:

🚀 GitHub Pages (Enlace Permanente + Instalar App)

Descarga el archivo ya renombrado como index.html listo para subirlo directo a GitHub sin cambiarle el nombre:

  1. Descarga index.html con el botón verde de abajo y súbelo a tu repositorio público en github.com.
  2. Activa Settings → Pages (Branch: main / root) para obtener tu enlace permanente.
  3. Abre ese enlace github.io en Chrome y toca "Instalar aplicación" (o los 3 puntos ⋮ → Instalar aplicación).
Opción A: Acceso Directo Local en Chrome (Sin internet)
  1. Toca los 3 puntos (⋮) de Chrome y presiona la estrella ★ Favoritos.
  2. En la pantalla principal de tu celular deja presionado un espacio vacío → Widgets → Chrome → Marcadores.
